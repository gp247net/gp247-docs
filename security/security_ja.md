# GP247 セキュリティリリース

## はじめに
このページは、`gp247/core`、`gp247/front`、`gp247/shop` の **3.x** 系のうち、**セキュリティ上の問題を修正した**リリースを新しい順に一覧にしたものです。
対象は**サイト運営者・管理者**です。稼働中のバージョンを「ひと目でわかる」の表と比べるだけで、サイトが安全か、更新が必要かがわかります。

| リポジトリ | 安全な最低バージョン | 最新のセキュリティ修正 |
| --- | --- | --- |
| gp247/core | **3.5.0** | 2026-10-28 |
| gp247/front | **3.0.1** | 2026-09-02 |
| gp247/shop | **3.3.1** | 2026-10-28 |

> ⚠️ **注意:** セキュリティ修正を受けられるのは **3.x** 系のみです。2.x で稼働中のサイトは 3.x へ移行してください。
> `gp247/shop` 3.3.1 には `gp247/core` 3.3 以上が必要です。両方を同時に更新してください。

> 💡 **稼働中のバージョンの確認:** `php artisan gp247:info`、または `composer show "gp247/*"`。

## サーバーソフトウェア（PHP・Web サーバー）
GP247 は、お客様またはホスティング事業者がインストールした PHP と Web サーバーの上で動作します。これらの不具合は GP247 の
リリースではなく各提供元が修正します。こちらも最新の状態に保ってください。

| 日付 | ソフトウェア | 問題 | 修正済みバージョン（PHP 公式リリース） |
| --- | --- | --- | --- |
| 2026-10-21 | PHP | **PHP2Shell** — リモートコード実行、深刻度: 緊急（CVE-2026-109618、CVE-2026-109619） | 8.3.36 · 8.4.27 · 8.5.12 |

**対応方法**
1. 稼働中の PHP バージョンを確認します: `php -v`、または **管理画面 → サーバー情報**。
2. 公式リリース（php.net、公式 Docker イメージ、バージョンを選べる多くのコントロールパネル）の PHP の場合:
   使用中のブランチの修正済みバージョン以降に更新します。
3. Linux ディストリビューション（Ubuntu、Debian、RHEL など）がインストールした PHP、またはホスティング事業者が管理する PHP の場合:
   古いバージョン番号のまま修正が適用されることが多く、**バージョン番号だけでは安全かどうか判断できません**。OS の最新アップデートを
   適用するか、CVE-2026-109618 と CVE-2026-109619 が修正済みか事業者に確認してください。
4. すぐに更新できない場合: `php.ini` で `session.upload_progress.enabled = Off` を設定し（GP247 はこの機能を使いません）、PHP を
   再起動します。リスクは下がりますが、更新の代わりにはなりません。
5. Docker で S-Cart を運用している場合: [DOCKER.md](https://github.com/gp247net/s-cart/blob/master/DOCKER.md) の **Security updates** に従ってください。

## 更新方法
1. データベースとサイトのフォルダーをバックアップします。
2. コードを更新します。
   ```bash
   composer update gp247/core gp247/front gp247/shop
   ```
3. データ・設定・キャッシュの更新を適用します。
   ```bash
   php artisan gp247:update
   ```
4. `php artisan gp247:info` でバージョンを再確認します。

詳しい手順は [GP247 の更新](https://gp247.net/ja/docs/system/how-to-update-gp247.html)をご覧ください。

## 脆弱性の報告
脆弱性を見つけた場合は、**support@gp247.net** へメールでお知らせください。修正版の公開前に問題が広まらないよう、GitHub の公開 Issue は**使わないで**ください。

## よくある質問（Q&A）
**Q1: 自分のサイトは影響を受けますか？**

→ 稼働中のバージョンを「ひと目でわかる」の表と比べてください。いずれかのリポジトリが最低バージョン未満であれば、更新が必要です。

**Q2: マルチストアや API を使っていなくても、更新は必要ですか？**

→ 「（マルチストアのサイト）」「（API を有効にしたサイト）」と書かれた行は影響しませんが、それ以外の行は影響します。最低バージョンへの更新を常におすすめします。

**Q3: まだ 2.x を使っている場合は？**

→ 2.x 系はセキュリティ修正の対象外で、このページにも記載していません。更新ガイドに沿って 3.x（「ひと目でわかる」の表の最低バージョン）へ移行してください。

**Q4: なぜ問題の悪用方法を詳しく説明しないのですか？**

→ 未更新のサイトを狙う攻撃者の手がかりにならないようにするためです。このページでは、問題の種類、影響範囲、修正済みリリースのみを記載しています。
