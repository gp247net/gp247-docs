# Danh sách lệnh CLI đã chuyển sang bộ tài liệu Dòng lệnh

## Giới thiệu
Trang tra cứu lệnh `gp247:*` cũ đã được thay bằng bộ tài liệu [Dòng lệnh GP247 (CLI)](../cli/cli-introduction_vi.md),
chia theo việc cần làm và có đánh dấu mức an toàn của từng lệnh. Trang này chỉ còn để link cũ dẫn bạn tới đúng chỗ. Tìm nội
dung bạn cần trong bảng dưới.

## Nội dung cũ nằm ở đâu

| Bạn đang tìm | Trang mới |
| --- | --- |
| Bảng tra nhanh mọi lệnh | [Dòng lệnh GP247 (CLI)](../cli/cli-introduction_vi.md#bảng-tra-toàn-bộ-lệnh) |
| `gp247:install`, `gp247:update`, `--publish`, lệnh `core-*` / `front-*` / `shop-*` / `mcp-*`, `language-update`, `shop-sample` | [Cài đặt & cập nhật](../cli/cli-install-update_vi.md) |
| Họ lệnh `gp247:ext-*`, license, `make-plugin`, `make-template` | [Extension](../cli/cli-extensions_vi.md) |
| `template-publish`, `template-prune`, `template-setup`, các tag `vendor:publish` | [Template](../cli/cli-templates_vi.md) |
| `gp247:doctor` và từng mục kiểm, `gp247:info`, `gp247:core-info`, `gp247:cache-rebuild` | [Kiểm tra & chẩn đoán](../cli/cli-diagnostics_vi.md) |
| `gp247:admin-password`, `gp247:encryption-key-rotate`, `gp247:backup-*`, `gp247:shop-clear-cart` | [Bảo trì](../cli/cli-maintenance_vi.md) |
| Kết quả `--json`, mã thoát, mã lỗi, chạy trong script / CI / Docker | [Script, CI & Docker](../cli/cli-automation_vi.md) |

## Hỏi & Đáp (Q&A)
**Câu 1: Trang này có còn được cập nhật không?**

→ Không. Mọi thay đổi về lệnh chỉ được ghi ở bộ tài liệu [Dòng lệnh GP247 (CLI)](../cli/cli-introduction_vi.md).
