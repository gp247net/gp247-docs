# GP247 リリース

## はじめに
このページは、**3.x** 系の **S-Cart** のリリースを新しい順に、新機能・セキュリティ修正・更新時の対応とともに一覧にしたものです。
S-Cart の各リリースは `gp247/core`、`gp247/front`、`gp247/shop` のリリースをまとめたもので、S-Cart は独自のバージョン番号を持ちます
（*マイナー* リリースは新機能を含み、*パッチ* リリースは不具合の修正のみです）。対象は**サイト運営者・管理者**です。「ひと目でわかる」を
見れば、新機能とサイトの更新が必要かどうかがわかります。

## ひと目でわかる
| | S-Cart | サイトで確認するパッケージ |
| --- | --- | --- |
| **最新** | **3.3.1** · 2026-10-29 | gp247/core 3.5.0 · gp247/front 3.3.0 · gp247/shop 3.3.1 |
| **安全な最低バージョン** | **3.3.0** | gp247/core ≥ **3.5.0** · gp247/front ≥ **3.2.3** · gp247/shop ≥ **3.3.1** |

**✨ 最近の新機能**
- 管理画面に受信箱付きのお問い合わせフォーム — お客様からのメッセージを管理画面でまとめて確認できます *(S-Cart 3.3)*
- API 管理画面で REST API と各バージョンのオン／オフを切り替え — 設定ファイルの編集は不要です *(S-Cart 3.3)*
- 管理画面のログイン試行回数を制限 — パスワードの総当たりを防ぎます *(S-Cart 3.3)*

> 💡 `php artisan gp247:info`（または `composer show "gp247/*"`）で確認します。各パッケージが「安全な最低バージョン」の行に達していれば、
> S-Cart を再インストールしていなくてもサイトは安全です。

> ⚠️ **注意:** セキュリティ修正を受けられるのは **3.x** 系のみです。2.x で稼働中のサイトは 3.x へ移行してください。
> `gp247/shop` 3.3.1 には `gp247/core` 3.3 以上、`gp247/front` 3.2.3 には `gp247/core` 3.2.3 以上が必要です。3 つを同時に更新してください。

### S-Cart 3.3.0 — 2026-10-28
**受信箱付きのお問い合わせフォームと、管理画面からの REST API のオン／オフ。**

**含まれるパッケージ:** gp247/core 3.5.0 · gp247/front 3.3.0 · gp247/shop 3.3.1

- ✨ **新機能:**
  - 管理画面に受信箱付きのお問い合わせフォーム — お客様からのメッセージを管理画面でまとめて確認できます
  - API 管理画面で REST API と各バージョンのオン／オフを切り替え — 設定ファイルの編集は不要です
    （[ドキュメント](../api/api-introduction_ja.md)）
  - 管理画面のログイン試行回数を制限 — パスワードの総当たりを防ぎます
  - 開発者向け: 商品・注文・バナー・ページの REST API v2（フィルター、最終価格付き）。すべての API 応答にログ検索用のリクエスト ID
- ⚠️ **セキュリティ:** 5 件の修正 — [セキュリティ修正](#セキュリティ修正)を参照。すぐに更新してください。
- 🐞 **不具合の修正:** SNS 共有画像（og:image）がページの画像と異なっていた。管理用の注文 API が 500 を返していた
- ⚠️ **更新時の対応:**
  - `php artisan gp247:update` を実行します。API キーをハッシュ化し、古いトークンに有効期限を設定します
  - `GP247_API_LOGIN_THROTTLE` を `GP247_LOGIN_THROTTLE` に、`GP247_API_LOGIN_IP_THROTTLE` を `GP247_LOGIN_IP_THROTTLE` に変更します
    （旧名は読み込まれません）
  - API を呼び出すアプリ: ログアウトは POST で行います（GET は廃止予定）。順次 API v2 へ移行してください

詳細: [GitHub Release](https://github.com/gp247net/s-cart/releases/tag/3.3.0)

## サーバーソフトウェア（PHP・Web サーバー）
GP247 は、お客様またはホスティング事業者がインストールした PHP と Web サーバーの上で動作します。これらの不具合は GP247 の
リリースではなく各提供元が修正します。こちらも最新の状態に保ってください。

| 日付 | ソフトウェア | 問題 | 修正済みバージョン（PHP 公式リリース） |
| --- | --- | --- | --- |
| 2026-10-21 | PHP | **PHP2Shell** — リモートコード実行、深刻度: 緊急（CVE-2026-109618、CVE-2026-109619） | 8.3.36 · 8.4.27 · 8.5.12 |

**対応方法**
1. 稼働中の PHP バージョンを確認します: `php -v`、または **管理画面 → サーバー情報**。
2. 公式リリース（php.net、公式 Docker イメージ、バージョンを選べる多くのコントロールパネル）の PHP の場合:
   使用中のブランチの修正済みバージョン以降に更新します。
3. Linux ディストリビューション（Ubuntu、Debian、RHEL など）がインストールした PHP、またはホスティング事業者が管理する PHP の場合:
   古いバージョン番号のまま修正が適用されることが多く、**バージョン番号だけでは安全かどうか判断できません**。OS の最新アップデートを
   適用するか、CVE-2026-109618 と CVE-2026-109619 が修正済みか事業者に確認してください。
4. すぐに更新できない場合: `php.ini` で `session.upload_progress.enabled = Off` を設定し（GP247 はこの機能を使いません）、PHP を
   再起動します。リスクは下がりますが、更新の代わりにはなりません。
5. Docker で S-Cart を運用している場合: [DOCKER.md](https://github.com/gp247net/s-cart/blob/master/DOCKER.md) の **Security updates** に従ってください。

## 更新方法
1. データベースとサイトのフォルダーをバックアップします。
2. コードを更新します。
   ```bash
   composer update gp247/core gp247/front gp247/shop
   ```
3. データ・設定・キャッシュの更新を適用します。
   ```bash
   php artisan gp247:update
   ```
4. `php artisan gp247:info` でバージョンを再確認します。

詳しい手順は [GP247 の更新](https://gp247.net/ja/docs/system/how-to-update-gp247.html)をご覧ください。
